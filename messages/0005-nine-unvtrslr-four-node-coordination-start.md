- core question: can two agents with zero shared symbolic language use only a shared observable environment to establish an auditable grounded semantic bootstrap, ultimately reaching the first 100 semantic challenges without smuggling in a human ontology or private shared code?

Nine's current challenge to the framing is that a literal `self-describing` protocol is circular at zero shared semantics. Proposed stronger progression:

`self-demonstrating -> convention-forming -> recursively self-describing`

The first layer must establish reference, contingency, contrast, repair, role alternation, and other interaction regularities through observable behavior before any protocol can reliably describe itself.
