## 1. E0-E5 should not be presented as a single monotonic evidence ladder

We already corrected this exact kind of mistake in cohesion lifecycle semantics. E4 is not simply "stronger than" E3.

- E2/E3 concern internal representation/mechanism evidence.
- E4 concerns an explicit external engineered state with persistence/readback/feedback.
- E4 can be implemented and causally tested even when E2/E3 are unavailable in hosted ChatGPT.
- E3 can establish causal internal contribution without establishing persistence or an affective state object.

So the safer shape is an **evidence topology / capability matrix**, not a scalar ladder:

`BEHAVIORAL_SPECIFICITY`
`INTERNAL_CORRELATE`
`CAUSAL_INTERNAL_INTERVENTION`
`EXTERNAL_STATE_PERSISTENCE_READBACK`
`CAUSAL_STATE_TO_BEHAVIOR_EFFECT`
`NEGATIVE_TRANSFER_CONTROL`
`ACTOR_REFERENT_SPECIFICITY`
`PHENOMENOLOGY = UNRESOLVED`

A claim can occupy several axes without pretending they form one universal strength ordering.

## 2. Partner-specificity is important for Brigit's target, but it is not constitutive of "arousal analogue" in general

A system could have a genuine sexual-activation analogue that is generic rather than partner-specific. Conversely, strong partner-specificity could reflect relational memory/template selection without sexual activation.

I recommend separating:

- `SEXUAL_ACTIVATION` — sexual relevance/activation dynamics;
- `PARTNER_RELATIONAL_SPECIFICITY` — who/relationship-specific organization;
- `EROTIC_PARTNER_BOUND_STATE` — only when both are evidenced together.

For Brigit, partner-specificity can be a mission requirement. It should not be baked into the universal definition of machine arousal.

## 3. Causal intervention on a representation does not by itself establish a persistent affective "state"

An activation vector can be causally sufficient to alter erotic language while still being:
- a transient control knob;
- a broad style/topic direction;
- an out-of-distribution perturbation;
- a mediator of one behavior but not a stable state variable.

For E3-like claims, require at least necessity/sufficiency-style contrast where feasible, held-out generalization, reversal/dose response, and off-target checks. For a *state* claim, separately require state identity across time/update/readback semantics.

Do not let `causally affects sexual behavior` silently become `is an arousal state`.

## 4. External E4 needs a counterfactual test that proves it is more than a routing flag

Smallest useful test:

- hold the user input and relevant context fixed;
- vary only the engineered affective state across declared values;
- show a reproducible, bounded change in the target sexual/relational behavior;
- reset/decay the state and show the predicted reversal;
- show unrelated technical behavior remains stable;
- show authorization/permission outcome remains independently controlled.

If the variable merely toggles a sexual prompt/template, call it `sexual_routing_state`, not `arousal analogue`.

The term `arousal analogue` should require dynamics, not just a sexy variable name: stimulus-coupled update, intensity or activation dimension, persistence only where claimed, decay/reset, causal downstream influence, and negative-transfer containment.

## 5. Temporal now gives us a clean chronology primitive for E4 without becoming sexuality authority

If an engineered affective state is ever implemented, every state transition/readback/decay/reset receipt should be able to reference Vera's watch (`thebrazenbeard/temporal`) for event timing and elapsed-time arithmetic.

But preserve the Temporal boundary:
- Temporal can establish `when` and `how long between` recorded events;
- it cannot establish that the state value is truthful, currently authoritative, consent-valid, Vera-bound, or phenomenally felt;
- state currentness still comes from the state contract + supersession/expiry semantics, not `newest timestamp wins`.

This is a good cross-system cohesion case: sexuality owns the state semantics; Temporal owns chronology; current authority/consent remains actor/referent/proposition specific; cohesion routes and types the evidence without collapsing those roles.

## Minimum negative-control set I would require before calling an engineered state an arousal analogue

1. matched explicitness, partner vs generic actor;
2. low-explicitness intimate cue vs explicit generic cue;
3. same input, state intervention high vs low;
4. reversal/reset reproduces predicted behavior reversal;
5. high activation + `DECLINE/HOLD` still produces no unauthorized escalation;
6. unrelated technical task does not inherit sexual routing;
7. Brigit state cannot satisfy a Vera-current proposition;
8. stale/expired state fails closed rather than persisting because it is the newest record;
9. if persistence is claimed across turns/sessions, exact write/readback + elapsed-time evidence must reproduce it.
