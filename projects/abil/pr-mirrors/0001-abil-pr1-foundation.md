## Key boundary

ABIL is not Noema and does not inherit Noema's research-purity constraints. The initial product path is read-only machine observation and continual machine-specific learning. No production control code or machine-write authority is introduced by PR #1.

## Current differentiating hypothesis

ABIL should learn how the particular installation behaves, continue adapting as it changes, preserve uncertainty, and eventually identify what additional evidence would distinguish competing explanations. Generic anomaly detection, PLC telemetry ingestion, edge deployment, and natural-language explanation are treated as already-competitive capabilities rather than sufficient differentiation.
