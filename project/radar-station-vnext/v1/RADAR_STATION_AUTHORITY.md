## Distinct permission surfaces

Treat these separately:

- **Native Project control:** instructions/files/memory/project settings.
- **GitHub:** repository reads/writes, PRs, merges, branch/ref/settings/rules changes.
- **Supabase/provider:** schema/data/functions/config/deploy/runtime operations.
